# DraBornGames

DrabornEagle oyun projeleri.

## DraBornGo / Son Kilometre

[DraBornGo-LastMile](./DraBornGo-LastMile) — Android Expo Go SDK 57 üzerinde çalışan, yerel demo verili dikey 3D kurye kariyer oyunu.

Kurulum, kapsam, testler ve sürüm notları oyun klasöründedir. Gerçek ödeme, ödül ve sunucu doğrulaması bu demo sürümünde etkin değildir.

## DraBornLand

[DraBornLand](./DraBornLand) — Expo Go 58.0.2 ve web için üçüncü şahıs ada survival oyunu. Kaynak toplama, crafting, barınak inşası, gece yaratıkları, üç antik mühür, ejderha ve deniz feneri görevi içerir. Lokal kayıt ve cihazlar arasında JSON aktarımı desteklenir.

Web: [www.draborneagle.com/DraBornGames/DraBornLand](https://www.draborneagle.com/DraBornGames/DraBornLand/). Termux kurulumu ve test kanıtları oyun klasöründedir.
